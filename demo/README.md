# Demo charts

These `.wiki` files are copyable examples for MonsterEvolution features. They intentionally contain no third-party images. Where a chart names a local file, upload or rename an image on your own wiki and update the example filename.

| File | Demonstrates |
| --- | --- |
| `ComplexEvolution.wiki` | Generic branches, merges, conditions, and fusion. |
| `PokemonEevee.wiki` | A wide branch with item icons above and beside labels. |
| `DigimonAgumon.wiki` | A franchise whose evolution routes vary by game and continuity. |
| `LumenTaleStarters.wiki` | Multiple disconnected starter lines. |
| `CoromonToruga.wiki` | A compact level-based chain. |
| `AnodeHeartBranches.wiki` | Stat and held-item branches. |
| `TemtemCrystle.wiki` | “Levels gained” requirements in a vertical chain. |

Names and trademarks belong to their respective owners. The examples are documentation of wiki markup, not bundled game data or artwork. Evolution details can vary between releases; verify them against the game/version documented by your wiki.
